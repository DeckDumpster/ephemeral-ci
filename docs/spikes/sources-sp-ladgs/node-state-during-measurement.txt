#            TLS verified against the cluster CA /etc/pve/pve-root-ca.pem, which was
#            itself bootstrapped from GET /nodes/hypervisor/certificates/info over a
#            channel pinned to the leaf SPKI

#            with `openssl verify` to actually sign that leaf.

#            A vCPU scaling curve measured on a contended box can understate the
#            benefit of more vCPUs, so the node's own state is part of the evidence
#            for every number in the write-up. Snapshots are appended per run.
